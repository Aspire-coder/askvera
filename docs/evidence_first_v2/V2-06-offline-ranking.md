# V2-06 owned offline ranking

This is a closed synthetic structural experiment. Real saved ranking evidence is **UNAVAILABLE**. No provider, model, index, network, AWS, or answer-generation call is made or implied.

`ranking_fixture.authority()` owns the one canonical manifest. Its ordered IDs, read-only records, and convenience fixture tuple all derive from one immutable authority. Admission never uses a caller registry or a mutable fixture alias. Each record is checked against the immutable, versioned pre-exposure ledger by stable request/source-content lineage. That lineage deliberately excludes family, review judgment, provenance, and split labels, so relabeling or promotion fails while distinct same-family development cases remain distinct.

The retained surface has exactly two routes:

- `run_owned(case_ids, run_id, parameters, registry_version, authority_content_id, ledger_version, ledger_content_id)`
- `validate_owned(expected_canonical_ids, expected_order, run_id, parameters, registry_version, authority_content_id, ledger_version, ledger_content_id, report)`

The ranking module pins the reviewed authority records, canonical order, authority version/content identity, approved markets, analyzer configuration identity, and ledger assignment tuple/version/content identity by value at import. Fixture suppliers and exported aliases are inspection-only. The validator receives all authority and ledger expectations independently and replays only those pinned records. It rejects mutable-state substitutions, unknown or duplicate IDs, reordered cases, changed versions/content identities, run, parameters, capture identities, rows, axes, or checksum. Reviewed identifiable unavailable and rejected captures become report rows with typed nonblank reasons; malformed or unknown IDs fail before a report exists.

Every report has exactly the synthetic/real by development/held-out axes. Rows occur once. State counts and global/axis totals conserve exactly. Every strategy retains top-1, top-k, rank, and MRR. Misses, judged-empty results, unavailable, and rejected outcomes have no rank and zero MRR; only completed rows contribute to denominators. `top_k` changes row metrics. RRF is fixed at 60. Strategy weights are the only weight authority and are scaled before accumulation to keep finite comparisons finite. Channel configuration binds the pinned analyzer content identity, depth, closed complete/empty/failed status union, scores, and ranks. Approved markets, policy/directory source-country rules, internal-access entitlement, and reviewer/judgment/span witness identities are checked structurally.
