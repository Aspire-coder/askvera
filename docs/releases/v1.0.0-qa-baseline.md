- Country-aware global directory retrieval
- Source-aware directory field extraction
- Business-hours restoration when a value is omitted by generation
- FBO versus Preferred Customer label protection
- Source-gated correction of contradictory directory values
- Requested-field focus for telephone, email, website, address, hours, and order-size questions

- Typo-safe retrieval ranking
- Follow-up question context handling

## QA scope

QA should treat this tag and commit as the fixed starting point for testing.
Any failure found against this version should be logged as a Jira bug and linked
to the failing test case. Do not compare results against an older production
deployment without recording the older commit and widget version.
